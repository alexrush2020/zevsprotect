# zevsprotect® — прототип корпоративного сайта

Кликабельный прототип нового сайта бренда **зевспротект®** (замена [zevsprotect.ru](https://zevsprotect.ru/)). Это не продакшен с 1С и Битрикс24, а рабочий срез витрины, каталога и B2B-заказа.

Слоган бренда: **Сила в ваших руках.**

## Что можно пройти

- Главная: производство, категории, хиты, условия, отзывы, статьи, заявка
- Каталог с фильтрами: вид защиты, основа, покрытие, цвет, размер, поиск, сортировка
- Карточка товара: галерея, остаток / «под заказ», сертификаты PDF, SEO-блок
- Корзина, гостевой и авторизованный checkout с выбором ТК и НДС 20%
- Счёт на печать/PDF, счёт от менеджера, мок ЮKassa (`/pay/:id`, successUrl, failUrl)
- Отслеживание гостевого заказа по номеру и email (демо `ZP-10990` / `gost@example.ru`)
- Сброс пароля и мок-ссылка из письма `/forgot/reset`
- Личный кабинет, статусы заказа, повтор заказа
- Образцы, расчёт поставки, прайс (таблица + CSV)
- Сравнение доставки (СДЭК, ДЛ, ПЭК, Энергия, самовывоз)
- О компании: география, качество, сертификаты, сестринский бренд зевстекс®
- WhatsApp / MAX, cookie-баннер, политика ПДн
- Макет админки без редактирования каталога

Цены, остатки и фото — с действующего сайта, в интерфейсе помечены как данные 1С. Заказы и заявки пишутся в `localStorage`. Обмен с 1С КА 2, Битрикс24 и ЮKassa показан журналом событий на заказе.

## Запуск

```bash
npm install
npm run dev -- --port 43127
```

Открыть [http://localhost:43127](http://localhost:43127).

Демо-кабинет: `zakup@roststroy.ru` / любой пароль (`demo`).

Прайс CSV: `/api/pricelist`.

## Стек прототипа

Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui.

## Дизайн

Брендбук: тёмно-синий `#040040`, белый, чёрный. Знак-молния + wordmark `zevsprotect` / `зевспротект`, слоган «Сила в ваших руках». Малиновый `#B4003C` — бренд `зевстекс®`, на этом сайте не ведущий. Логотипы лежат в `public/brand/`, текстовые константы — в `lib/brand.ts`.
