# Требования: сводка ТЗ и КП

Первоисточники: [ТЗ](source/Техническое%20задание%20на%20разработку%20корпоративного%20сайта%20«ЗевсПротект».docx), [КП](source/КП_ЗевсПротект2%20(2).docx), итоги показа прототипа — [meetings/](meetings/). При расхождении читать первоисточник; ответы заказчика из раздела ТЗ «Требования, требующие уточнения» и решения встреч — более поздние и имеют приоритет над основным текстом ТЗ.

Бюджет 537 000 ₽, срок 3 месяца. Аудитория — B2B: дистрибьюторы, закупщики, предприятия, DIY-сети. Заменяем https://zevsprotect.ru/ (WordPress).

## Структура

Главная · О компании · Каталог · Карточка товара · Корзина · Оформление · ЛК · Блог (список, статья) · Контакты · Политика ПДн · служебные страницы. Прототип (основа кода) дополнительно содержит: расчёт поставки, прайс, образцы, сравнение ТК, трекинг, отзывы, чат менеджера, избранное, вход через Яндекс (заглушка) — см. [CONTRADICTIONS.md](CONTRADICTIONS.md).

## Ключевые требования (ID используются в карточках доски)

| ID | Требование | Источник |

| T-ABOUT | О компании: описание, производство, фото, контроль качества, сертификаты, преимущества, география; редактируется в админке | ТЗ, КП 3.3 |
| T-CAT | Каталог: дерево категорий (7 шт.), список, карточки, сортировка, фильтры (основа, покрытие, цвет, размер), поиск, пагинация, в корзину | ТЗ, ответы 1–3 |
| T-PDP | Карточка: название, артикул, фото, описание, характеристики, размеры, цена, наличие, мин. партия, упаковка, сертификаты, количество, в корзину, оформить, запрос/заявка, похожие | ТЗ, КП 5.2 |
| T-CART | Корзина: добавить/удалить/изменить количество | ТЗ, КП 5.3 |
| T-CHK | Оформление: ФИО/организация, телефон, email, доставка, комментарий, состав, итог, способ оплаты, согласие ПДн. Без регистрации можно; из ЛК — автоподстановка | ТЗ, ответы «Заказы» 1–2 |
| T-PAY | Оплата: по счёту (менеджер вручную **или** сайт формирует счёт по запросу пользователя) + онлайн (любой популярный провайдер) | ТЗ, ответы «Оплата» |
| T-ST | Статусы заказа: принят → в сборке → отгружен в ТК → в доставке → доставлен / отменён. Источник статуса — Битрикс24 | ответы «Заказы» 3–4 |
| T-REPEAT | Повторить прошлый заказ с перерасчётом цен | ответы «Заказы» 5 |
| T-LK | ЛК: профиль, правка контактов, история, заказ, статус заказа и оплаты (оплата видна только при наличии ЛК) | ТЗ, ответы «Оплата» 4 |
| T-AUTH | Регистрация email/телефон, вход логин+пароль, восстановление пароля; разграничение гость/клиент | ТЗ, КП 6.1–6.2 |
| T-FORM | Обратная связь: имя, телефон, email, сообщение, организация, согласие ПДн → сообщение об успехе, сохранение в админке + лид в Б24 | ТЗ, КП 6.5–6.6 |
| T-BLOG | Блог: список, категории, поиск, пагинация, статья (дата, картинка, заголовок, анонс, текст, SEO, связанные) | ТЗ |
| T-ADM | Админка: страницы/тексты/картинки/баннеры/SEO; блог; каталог (категории, товары, характеристики, фото, цены, остатки, публикация); заказы (состав, клиент, статусы, оплата, доставка); роли | ТЗ, КП 4.1–4.6 |
| T-1C | 1С КА 2 → сайт: товары, категории, характеристики, цены, остатки, доступность. Сайт → 1С: клиенты, заказы. Ручная правка товаров в CMS на случай ошибок 1С | ТЗ, ответы «Каталог» 4–5, «Интеграции» |
| T-B24 | Битрикс24: регистрация → компания; заказ зарегистрированного → сделка (счёт и онлайн); заявка на расчёт/консультацию → лид; данные заказа полностью; статусы из Б24; повторная отправка при ошибке | ТЗ, ответы «Интеграции» 3 |
| T-SEO | ЧПУ, meta, sitemap.xml, robots.txt, микроразметка, SEO-поля в админке | КП 9.1–9.2 |
| T-AN | Яндекс.Метрика + GA; события: просмотры, товар, корзина, начало/успех оформления, онлайн-оплата, формы, регистрация, авторизация | ТЗ «Аналитика» |
| T-OUT | Вне базовой оценки: калькулятор доставки (выбор ТК, виджеты ТК, от 45 000 ₽), хостинг, контент, лицензии | КП §6, §8 |

## Открытые вопросы бизнесу

См. карточки `own=business` на доске и [CONTRADICTIONS.md](CONTRADICTIONS.md). Ответ «как обрабатывать ошибки обмена» заказчик отложил — принимаем по умолчанию: очередь с повторами и ручной переотправкой из админки.
