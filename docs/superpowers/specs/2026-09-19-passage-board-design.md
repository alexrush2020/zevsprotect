# Доска в проходной — главная

Заменить секцию «Отзывы закупщиков» на главной заводской доской с табличками. Стена читается без клика. Цитата — награда за любопытство, не абзац на карточке.

## Задача

Сейчас на главной три одинаковые карточки с цитатой и номером `01`. Это офисный виджет. Нужна доска в проходной: тёмный металл, тяжёлые таблички, имена фирм, годы. Без звёзд, аватаров, карусели и кнопки «оставить отзыв».

Секция стоит на главной между блоком «Условия покупки» / «Персональные условия» и блоком «Статьи». Другие страницы не трогаем.

## Первый кадр

Полная ширина, тёмный фон в духе секции «Почему закупают у нас».

- Водяной знак сзади: `ПРОХОДНАЯ` — как сейчас `zevs` в тёмной секции преимуществ.
- Фон: тёмный металл, зерно (`home-grain`), клёпки, горизонтальная рейка для табличек. Не фото цеха и не лица.
- Ярлык: `Доска в проходной`.
- Заголовок: `Кто берёт и не уходит`.
- В покое цитат на стене нет.

Три живые таблички крупные и тяжёлые, висят на рейке. За ними второй ряд мелких выцветших клейм: часть имён читается, часть закрыта чертами. Клейма не кликаются и не фокусируются.

Под рейкой одна глухая строка: `Остальные не вывешиваем`. Кнопки нет. Следом на главной уже идёт расчёт партии.

## Табличка в покое

На живой табличке только:

| Поле | Назначение |
|---|---|
| Компания | Трафарет, главное имя |
| Город | Только если есть в данных |
| Характер | Короткая вторая строка |
| Годы | `берут с 20XX` |

Три таблички:

1. **ООО «Анод»** — без города. Характер: `стабильность партий`. Годы: `берут с 2019`.
2. **ГК «Ланмар»** — без города. Характер: `ХБ · спилок · нитрил · КЩС`. Годы: `берут с 2021`.
3. **ООО «Арсеналтрейдинг»** — город: `Краснодар`. Характер: `отгрузка вовремя`. Годы: `берут с 2020`.

Годы выдуманы для витрины. Это не срок договора. Если появится реальная дата — меняется число, композиция та же.

## Паз

На десктопе наведение: табличка сходит с болтов вниз по рейке, кромка загорается оранжевым, как свежий шов. Под ней открывается паз.

В пазу:

- цитата из текущих отзывов, почти без правки;
- одна рубленая строка-факт.

Факты:

- Анод: `расхождения — в тот же день`
- Ланмар: `логотип · цена держится`
- Арсеналтрейдинг: `по срочным говорят сразу`

Цитаты — как в текущем каталоге, без переписывания смысла:

- Анод: `Стабильность поставок и качество партий. Менеджеры решают расхождения по артикулам в тот же день, без «перезвоним».`
- Ланмар: `Берём ХБ, спилок, нитрил и КЩС. Можно нанести логотип, цена держится при регулярном объёме.`
- Арсеналтрейдинг: `Ассортимент широкий, отгрузка вовремя. Важно, что по срочным заказам сразу говорят, реально это или нет.`

Одновременно открыта одна табличка. Соседние остаются на месте и чуть тускнеют.

На телефоне открывает удар (тап). Повторный тап или удар по другой табличке закрывает предыдущую. Свайпа и автоплея нет.

Клавиатура: живые таблички — кнопки, ход по Tab, Enter или пробел открывает и закрывает. `aria-expanded` отражает паз.

Если включено «меньше движения»: паз появляется без схода с болтов. Оранжевая кромка и текст остаются.

Фоновые клейма не реагируют. Анимация короткая, сдвиг железа, не пружина лендинга.

## Данные

Расширить записи `reviews` в `lib/data/catalog.ts`:

```ts
{
  company: string
  city?: string
  line: string
  since: number
  text: string
  fact: string
}
```

Фоновые клейма — массив из восьми подписей рядом с `reviews` в `lib/data/catalog.ts`. Четыре читаемые, четыре закрытые чертами. Ссылок нет.

Читаемые: `Севстальснаб`, `Югметалл`, `Донтехмонтаж`, `Прибой`.  
Закрытые: `——————`, `—— · ——`, `**** ****`, `······`.

Пустого состояния нет: три таблички всегда на рейке. Сети нет: это витрина, не отзыв с сервера.

## Сборка

- Новый клиентский компонент `components/home/passage-board.tsx`.
- В `components/home/home-view.tsx` вырезать сетку из трёх `blockquote` и вставить `<PassageBoard />`.
- Заголовок и водяной знак живут внутри доски, не снаружи.
- Одно состояние: индекс открытой таблички или `null`.
- Наведение открывает только при `(hover: hover) and (pointer: fine)`. Уход курсора с таблички закрывает её, если фокус не на этой табличке.
- На касании наведение не открывает: только тап по кнопке таблички. Ширину экрана для этого не используем.
- Повторить тёмную зернистую эстетику соседних секций (`bg-ink`, `text-paper`, `home-grain`, оранжевый акцент). Не вводить звёзды, логотипы партнёров и лица.

## Вне объёма

- Реальные годы сотрудничества и согласование с фирмами.
- Логотипы чужих заводов.
- Кнопка «оставить отзыв» / «встать на доску».
- Фото людей или цеха фоном.
- Карусель, автоплей, свайп.
- Отзывы на других страницах.
- Живая загрузка отзывов.

## Проверка

На главной, широко и на узком экране:

1. Стена читается без наведения: ярлык, заголовок, три имени, годы, фон из клейм, строка «Остальные не вывешиваем».
2. Открывается только одна табличка. Паз под ней, не сбоку.
3. На телефоне тап открывает и закрывает, свайпа нет.
4. Tab доходит до табличек, Enter/пробел работает, `aria-expanded` верный.
5. При «меньше движения» паз есть, табличка не едет.
6. Секции «Статьи» и «Нужен расчёт партии?» на месте, другие маршруты без изменений.
