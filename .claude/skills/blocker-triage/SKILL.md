# Проверка блокера

Следовать корневому AGENTS.md; отдельный план, отчёт или агент для этого навыка не обязательны.

1. Найти точное утверждение, основание и затронутый критерий. Проверить самым дешёвым способом: код/контракт/доступ/состояние своей среды. Сообщение агента без доказательства — гипотеза. Не выполнять пробную запись в рабочую БД ради проверки гипотезы.
2. Если путь уже существует — продолжить по нему, сняв блокер в текущей карточке. Если нет — выяснить конкретную зависимость и владельца; историю решений читать только когда она меняет выбор.
3. Техническое обратимое решение в границах задачи принять самостоятельно. Значимую продуктовую, денежную или правовую развилку передать владельцу с рекомендацией и существенными альтернативами; критерии молча не сужать. Независимую работу продолжать.
4. Зафиксировать итог один раз в карточке/плане. Материальное противоречие источников — CONTRA по AGENTS, архитектурное решение длительного действия — ADR, когда он нужен. Не дублировать одну находку во всех журналах.

Независимый взгляд нужен только при конкретном существенном риске по AGENTS. Не запускать обязательного скептика, двух ревьюеров или brainstorming для каждого блокера; если данные не изменились, повторный аудит не создаёт новых доказательств.
